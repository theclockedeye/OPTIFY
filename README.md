
# Optify

**Optify** is a repository developed as part of my internship at **Optifyx**. This project encompasses a series of tasks and assignments aimed at enhancing my skills and contributing to Optifyx's objectives.

## 📋 Tasks Assigned

1. **Task 1: Unit Converter**
   - *Description:* Developed an Android app for Unit Conversion.
   - *Technologies Used:*  AndroidStudio, Java,XML

2. **Task 2: Stopwatch**
   - *Description:* Developed a stopwatch application with start, stop, and reset functionalities.
   - *Technologies Used:*AndroidStudio, Java,XML.

3. **Task 3: User Authenticator**
   - *Description:* Implemented user authentication features including login, registration, and password recovery.
   - *Technologies Used:* AndroidStudio, Java,Firebase,XML.

4

## 🛠️ Getting Started

### Prerequisites

- Android Studio
- Java
- XML
- Git

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/theclockedeye/optify.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd optify
   ```

3. **Install frontend dependencies:**
   ```bash
   cd frontend
   npm install
   ```

4. **Install backend dependencies:**
   ```bash
   cd ../backend
   pip install -r requirements.txt
   ```
