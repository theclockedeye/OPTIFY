## 🛠️ Getting Started

### Prerequisites

- Node.js
- Python 3.x
- ASP.NET Core SDK
- Git

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/theclockedeye/optify.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd optify
   ```

3. **Install frontend dependencies:**
   ```bash
   cd frontend
   npm install
   ```

4. **Install backend dependencies:**
   ```bash
   cd ../backend
   pip install -r requirements.txt
   ```
